# Jobescape · лендинг C

Статический лендинг без сборки: HTML + CSS + JS.

```
index.html     разметка всех 10 секций
css/styles.css стили (mobile-first, брейкпоинт 768px)
js/main.js     навигация, меню, видео с главами, стрелки программ, липкая кнопка
images/        фото и постеры видео
media/         продуктовое видео (mobile / desktop)
```

## Запуск

```sh
python3 -m http.server 8000
# открыть http://localhost:8000
```

Видео подгружается только по http(s), поэтому лучше открывать через сервер, а не двойным кликом по файлу.

## Что осталось доделать

- Подписи `P1–P10` на странице — плейсхолдеры: скрины апки, фото людей, отзывы, бейджи сторов.
- Кнопки «Start quiz» ведут на `#quiz`. Когда будет квиз, замените ссылку в `index.html` (атрибут `data-cta`).
